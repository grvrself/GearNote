# GearNote 浏览器扩展

这是 Chrome/Edge 的 Manifest V3 扩展。先启动 GearNote 桌面程序，在「设置」页复制配对码，再通过浏览器扩展管理页的「加载已解压的扩展」选择本文件夹。打开扩展选项完成配对。

点击工具栏扩展图标时，扩展才会读取当前标签页。网页文章会发送标题、网址、正文和捕获时间；带字幕的视频会发送字幕时间点、字幕文本和语言。数据送到 `127.0.0.1:45147` 上的 GearNote 桌面程序。本机接口只接受 Chrome/Edge 扩展来源，并要求配对码；不会把资料发送到云端。扩展每 30 秒尝试连接一次，以更新桌面程序中的连接状态。

支持普通网页文章、YouTube 和 Bilibili 当前播放器提供的字幕，以及标准 HTML5/WebVTT 字幕轨道。`OK` 表示保存成功或资料已存在；`ERR` 表示捕获失败，把鼠标停在扩展图标上可查看原因。视频失败也会写入右栏，便于查看原因；在该视频页再次点击图标可重试。Bilibili 的部分字幕需要先登录。

Bilibili 字幕会从 `/x/player/wbi/v2` 获取。扩展会核对页面 BV 号、当前分 P 的 CID、接口响应身份，以及字幕地址中的 CID。匹配不明确时直接拒绝保存；不会回退到可能返回其他视频字幕的 `/x/player/v2`。

Bilibili 专栏（`/opus/` 和 `/read/cv`）只读取文章正文区域，不读取会员提示、评论和页面底部文案。如果正文尚未加载，扩展会显示失败原因；等待页面加载后重试。升级扩展和桌面程序后，在旧专栏页再次点击图标会更新原记录正文，保留原记录 ID。
