# KnowFlow

Tauri 2 + React + TypeScript + Vite 的桌面知识工作台原型。已接入浏览器扩展捕获网页文章与现有视频字幕、本机保存、右栏查看，以及基于已保存资料的 Agent 问答。

## 使用 Agent

1. 在桌面程序「设置 → Agent 服务」填写兼容 OpenAI Chat Completions 的 API 地址、模型 ID 和 API 密钥并保存。OpenAI 官方 API 地址为 `https://api.openai.com/v1`；其他服务商按其文档填写。
2. 在右栏展开真实保存的文章或带字幕视频，点击「加入本轮参考」。卡片会显示「本轮参考」标记，提问框下方会显示一行已选摘要；展开后可查看完整标题、定位或移除。失败记录和演示资料不能用于问答。
   也可以在当前会话的一条消息气泡中点击「选此消息为参考」，最多选 4 条。提问框会逐条显示所选消息的文字预览，并允许定位或移除；成功发送后清空这组临时选择。选中的旧消息即使已经被对话压缩覆盖，仍会以标明「用户消息」或「Agent 回答」的编号摘录进入本轮上下文。引用可定位回原消息；Agent 回答仅证明对话中曾这样说，不自动成为已核实的外部事实。
3. 在中栏输入问题，按 `Ctrl + Enter` 或点击「发送」。模型正文会逐步显示；回答中的 `[1]` 等编号对应本次发送的编号片段，下方来源按钮可定位文章、字幕时间点或对话原消息。输入区的「总结」使用同一资料选择。

输入问题后可点击「本轮上下文」查看发送前预览。预览与实际发送共用 Rust 的上下文组装模块，列出人格与回答规则、近期对话、选中的文章或字幕片段和文本字符用量。文本上限为 24000 字符；这是长度控制，不是精确的模型 token 数，图片另计。每轮最多选 8 个资料片段，近期对话最多纳入 8 条。超过 8 条未压缩消息时，可在「对话压缩」中调用当前模型生成较早对话摘要；原消息仍保存在数据库中，后续请求用摘要和最近的原消息组装上下文。摘要属于背景，不能代替可引用资料。截帧指令不调用模型，因此不显示上下文预览。

提问区默认只显示一行「本轮参考」摘要；点击可展开资料和消息的完整列表并移除。压缩对话、工作状态建议、编辑工作状态和项目记忆集中在提问区标题栏的「会话管理」中，打开时覆盖在聊天区上方，不占用平时的对话高度。

### 资料探索（第三阶段首个切片）

在已选参考资料的文本提问中，可勾选「资料探索」。模型最多进行 3 轮决策、6 次只读工具调用，在**本轮已选且处理成功的资料**里搜索片段并读取原文，再流式生成回答。回答中的「资料探索」折叠区保留搜索与读取步骤；来源编号仍可定位到对应记录或字幕时间点。该模式会增加模型请求次数、等待时间和 API 用量。图片提问与指定时间截帧暂不使用此模式。

工具记录会显示搜索命中数、读取的资料标题和对应来源编号。若模型在回答中写入本轮没有提供的数字来源编号，回答不会保存，提问框会保留原问题供重试。编号校验仅核对映射关系，不能自动判断模型的文字结论是否忠实于资料。

在「设置 → Agent 服务」可点击「测试已保存配置」检查资料探索兼容性。该测试只发送程序生成的虚构资料，不读取资料库或写入会话；可能产生少量模型 API 用量。结果显示搜索、读取是否实际调用及耗时。此测试不能替代用真实资料检查答案内容和引用准确性。

DeepSeek 的 Chat Completions 默认启用思考模式，而强制调用工具需要非思考模式；KnowFlow 在 DeepSeek 资料探索请求中明确关闭思考模式，普通问答不受影响。若服务拒绝强制调用，首轮会用自动模式重试；兼容性测试会显示未调用工具时的回退原因。

发送前的「本轮上下文」仅预览初始内容，不包含模型随后读取的片段；探索模式会为后续工具消息预留 7000 字符，其中工具输出最多 4000 字符。常见的工具调用不支持错误会提示并回退到原有的单次问答；其他服务端错误会直接显示。此能力仍需用实际配置的模型服务做端到端验收。

### 整理为笔记

带真实资料引用的 Agent 回答下方会出现「整理为笔记」。点击后进入「资料库」中的可编辑草稿；核对标题、正文及来源后点击「保存笔记」。草稿可追加到已有笔记，保存后的笔记可导出 Markdown。来源会保留原网页链接，视频引用还会标出时间点。笔记保存在本机应用数据目录的 `knowflow.db`，导出文件保存在其 `exports` 子目录。切换页面时，当前窗口中的未保存草稿会保留；关闭程序前请保存。

第五阶段已加入笔记正文的可控修改流程。选中已保存笔记，展开「Agent 修改建议与操作记录」，填写修改要求后生成建议；笔记标题、正文和要求会发送给当前配置的模型。模型只能提出追加文字或替换一处明确原文，不能修改标题、来源或直接写入。界面展示原文位置、新文字和理由；只有点击「确认并写入」才会修改笔记。确认、放弃、过期和撤销会写入本地操作记录；如果笔记后来又被修改，旧建议和撤销会被拒绝。当前仅支持正文不超过 12000 字的笔记生成建议。文件编辑、外部命令及通用模型写工具尚未开放。

会话管理中的「工作状态建议」也使用本地提案。界面逐项展示目标、已完成和下一步的原内容与建议内容；确认时只提交提案编号，由桌面端核对当前会话和状态版本后更新。放弃、过期、确认及撤销均有操作记录。程序重启后仍能查看待确认建议；工作状态后来被手动修改或自动追加完成记录时，旧建议不能确认，旧操作不能直接撤销。模型提出的“已完成”仍须用户核实。

模型请求由 Rust 端发送。问答时会发送本轮问题、选中的资料片段、近期对话，以及有内容的项目记忆、工作状态和较早对话摘要；主动点击压缩或生成工作状态建议也会向当前模型发送相关对话。Windows 版会使用当前用户的 DPAPI 加密 API 密钥，存于本机 `agent-key.bin`，重启后自动读取；密钥不会明文写入 `agent-config.json` 或显示在输入框里。地址和模型 ID 存于本机 `agent-config.json`。其他平台目前仍只在本次运行期间保留密钥。会话、消息和每个会话的参考资料存于本机 `knowflow.db`，主窗和小窗共用。首次启动新版时，会从旧 `chat-sessions.json` 或 `chat.json` 迁移，旧文件保留。请求失败会保留输入框内容并显示错误，不会伪造回答。

### 工作状态与本地存储

当前会话的「工作状态」记录目标、已完成事项和下一步。点击「生成建议」时，模型根据当前状态、较早对话摘要和最近 10 条消息提出修改，只有逐项核对并点击「确认更新」后才保存。用户也可以直接编辑并保存。保存笔记、捕获文章或字幕、完成视频画面分析等成功操作，会在当前会话已有目标时追加一条带操作编号的已完成记录；失败操作不会追加。它记录的是应用实际完成的动作，不代表模型分析内容已被用户认可。

资料、笔记、会话已从旧 JSON 文件迁移至 SQLite `knowflow.db` 的逐条表。首次升级已有数据库前，应用会在同一数据目录生成 `knowflow.pre-phase4.db` 备份；旧 JSON 文件和旧快照保留，但新版不再更新快照，后续修改以逐条表为准。右侧历史栏每页查询 20 条资料摘要，支持类型、标题、网站、正文与字幕搜索；展开记录时才读取完整内容。视频记录可按关键词与起止时间检索精确到秒的字幕。聊天、小窗和笔记来源只接收资料摘要，Agent 提问只复制本轮选中的完整资料。资料与笔记保存采用单项写入；会话和消息仍保留内存状态，但数据库只更新发生变化的行。旧版程序不能可靠读取升级后的新修改；回退时应恢复备份及匹配版本。模型地址、加密密钥、人格文件及视频画面文件仍分别保存。

### 会话管理

左栏会话区可新建、搜索、切换、重命名和删除会话。首次回答成功后，「新会话」会按第一条问题自动命名。每条会话分别保存消息与参考资料；右栏资料库由所有会话共用。追问会附带当前会话最近 8 条消息帮助理解语境，但事实引用只允许来自本次选中的资料。删除会话前会要求确认，删除最后一条后会自动创建空会话。窄窗口下点击左栏的会话图标打开列表。原快捷操作中的快捷键说明位于「设置 → 快捷键设置」，查找记录仍可按 `Ctrl + K`；小窗入口在右栏筛选行。

### 人格文件

在「设置 → 人格文件」可直接修改 Agent 的称呼和表达风格，点击「保存人格」后从下一次提问生效。默认人格是严谨、克制的知识管家，会自然地称呼用户为「先生」。点击「载入默认草稿」只修改编辑区，仍需点击保存；「撤销修改」可恢复上次保存的内容。

人格内容保存在本机应用数据目录的 `persona.md`。也可用文本编辑器修改该文件，再回到设置页点击「从文件重载」。人格文件控制表达方式，资料引用规则仍由问答程序约束。进行中的请求使用发送时已保存的人格快照。

### DeepSeek 返回 HTTP 400

如果使用 DeepSeek V4.1 Flash，API 地址填 `https://api.deepseek.com`，模型名称填 `deepseek-flash`。`DeepSeek-V4.1-Flash-1017` 是版本展示名，不能直接作为 API 的 `model` 参数。新版在这种配置下会给出明确提示；其他服务端错误会显示响应中的错误原因。修改设置后重新发送原问题即可。

## 捕获网页文章与视频字幕

1. 在此项目目录运行 `npm run tauri dev`，保持桌面窗口打开。
2. 点击应用左侧「设置」，在「网页文章捕获」区复制本机配对码。
3. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。开启「开发者模式」，点击「加载已解压的扩展」，选择本项目的 `extension` 文件夹。
4. 打开 KnowFlow 扩展的「扩展程序选项」，粘贴配对码，点击「连接本机程序」。
5. 打开网页文章，或打开带字幕的 YouTube / Bilibili 视频，点击浏览器工具栏中的 KnowFlow 扩展图标。扩展图标出现 `OK` 后，资料会进入桌面程序右栏。再次点击已保存的资料不会重复创建记录。

资料保存在 Tauri 应用数据目录的 `knowflow.db`。旧 `records.json` 与更早的 `articles.json` 会在首次启动时迁移；`records.json` 会保留作旧版备份，更早的 `articles.json` 会先沿旧版迁移流程改名为 `records.json`。桌面程序右栏只显示本机保存的真实资料；纯浏览器前端预览会显示样张。展开文章可阅读已保存正文；展开视频可查看字幕、字幕时间点及字幕语言。配对码保存在同目录的 `extension-pair-code.txt` 和浏览器扩展本地存储中。

视频必须有播放器提供的字幕轨道；无字幕时右栏会记录失败原因。Bilibili 的部分字幕需要先登录；若字幕提取失败，在视频页再次点击扩展图标可重试。YouTube 与 Bilibili 的播放器内部接口可能变化，届时失败记录会显示原因。需要语音识别的无字幕视频和结构特殊的网页仍待后续阶段。实际捕获动作由浏览器扩展图标触发。

### 视频画面分镜（首版）

展开已捕获的视频记录，点击「分析画面」。KnowFlow 调用内置的 dsh-video-storyboard 命令行引擎，从可访问的视频链接获取画面，生成最多 4 张分镜图及每格时间范围；结果保存在应用数据目录的 `storyboards/<记录 ID>/`，记录索引写入 `knowflow.db`。点击分镜时间点可在默认浏览器打开原视频。字幕捕获与画面分析分别进行；分镜拼图不会自动发送给模型。

在对话中只引用一条视频后，可以输入「截取 01:20 的画面」或「截图 01:02:20」。这是本地指令，无须配置模型 API；KnowFlow 会优先复用画面分析留下的视频缓存，再从指定时间取一张 JPEG，作为图片消息保存在当前会话。点击图片下方的「加入提问」并发送问题后，KnowFlow 才会将该 JPEG 随问题发送至当前配置的模型服务；该模型必须支持 OpenAI 兼容的视觉输入。图片提问会产生模型服务费用，纯文本提问不附带图片。若 B 站限制匿名取流且本机没有视频缓存，需先在记录栏使用登录态完成一次画面分析。

此功能需要 Node.js、`ffmpeg`、`ffprobe` 和 `yt-dlp`。Windows 预览目录的 `tools` 文件夹已放入经 SHA-256 校验的 FFmpeg 9.0.2 和 yt-dlp 2026.10.26，程序会优先使用它们，无须修改系统 PATH。重新从源码运行时，也可用 `winget install Gyan.FFmpeg` 安装 FFmpeg，并按 yt-dlp 官方说明安装其可执行文件。分析只适用于能够正常访问的视频；取流失败会在卡片中显示原因。画面分析需要下载视频并占用本地磁盘空间；下载缓存放在 KnowFlow 的应用缓存目录 `video-storyboard` 下，由分镜引擎按其缓存策略清理。项目源码位于 `vendor/dsh-video-storyboard`，按 Apache-2.0 许可证保留原作者 LICENSE 与 NOTICE。

B 站返回 HTTP 567 时，KnowFlow 会先用较低画质重试一次。仍需登录的内容可在出错卡片中主动选择仅含 B 站域名的 Netscape 格式 `cookies.txt` 再试。该文件包含登录凭据，请勿分享或放入源码仓库；KnowFlow 仅在本次分析中创建临时副本，任务结束后删除。浏览器扩展本身不会自动读取或上传登录 cookie。登录凭据过期、会员权限不足或站点限制时，仍可能无法取流。

### Bilibili 字幕匹配修复

旧版使用的 `/x/player/v2` 可能返回其他视频的字幕，即使响应中的 BV 号和 CID 看起来正确。新版改用 `/x/player/wbi/v2`，并核对页面 BV 号、当前分 P 的 CID、响应中的身份字段，以及字幕文件地址中的 CID。任何一项无法确认都会拒绝保存字幕，并在右栏显示失败原因。

新版首次打开时，会把此前保存但未验证来源的 Bilibili 视频字幕标为「提取失败」并移除错误正文；记录标题和网址会保留。关闭旧版程序、打开新版程序，在原视频页重新点击扩展图标即可覆盖这条记录。浏览器扩展也必须在扩展管理页点击「重新加载」。如果字幕地址未包含 CID，新版会选择失败提示，避免把不相关字幕作为正确结果。

### Bilibili 专栏正文修复

旧版可能把会员提示、页面标识和底部文案混入 `/opus/` 专栏正文。新版只从文章正文容器读取文字；若正文尚未加载会提示重试，不会抓取整页。先关闭旧桌面程序并打开新版，再在浏览器扩展管理页点击「重新加载」。回到原专栏页等待正文显示，点击扩展图标重新捕获。旧记录会在原位置更新，保留记录 ID 和对话引用。旧的错误文字在重新捕获前仍会显示。

## 在 Windows 上预览

在此文件夹打开 PowerShell：

```powershell
npm install
npm run tauri dev
```

首次运行可能编译 Rust 依赖。只看前端时运行 `npm run dev`，浏览器访问 `http://127.0.0.1:1420/`。浏览器预览没有原生窗口控制；请使用 Tauri 程序检查标题栏按钮。

当前源码构建的 Windows 程序位于 `src-tauri/target/release/knowflow.exe`，由 `npm run tauri -- build --no-bundle` 生成。此命令未制作完整安装包；单独复制 exe 不能保证分镜引擎、Node、FFmpeg 和 yt-dlp 等资源可用。开发和完整功能验证请运行 `npm run tauri dev`。旧整合预览包 `../KnowFlow-preview-storyboard/KnowFlow-vision.exe` 保留为历史产物，不包含本轮的资料探索改动。打开新版前请先关闭旧版；两个版本同时运行会占用相同的本机扩展连接端口。浏览器扩展有源码改动时，需在扩展管理页重新加载。

## 目前可操作的部分

- 右栏类型筛选、标题或来源搜索、记录展开、时间点选择和参考资料增删。
- 四种处理状态样张：字幕提取、摘要生成、可提问、提取失败。
- 故障卡片展示原因。视频失败后可在原页面再次点击扩展图标重试。
- 顶栏可以切换浏览器选项，并显示扩展连接状态。捕获说明入口展示扩展安装和配对步骤。
- Tauri 窗口使用无边框标题栏，可拖动、最小化、最大化或还原、关闭。
- 中栏可以移除本轮引用、展开或收起历史记录、发送问题，并从回答来源定位到右栏对应字幕时间点。
- 左栏包含导航与快捷操作。查找记录和 `Ctrl K` 会聚焦右栏搜索；文章与视频捕获说明入口打开扩展安装步骤；快捷键设置入口显示当前绑定。配置 Agent 并添加参考资料后可使用总结命令。
- 顶栏和左栏可打开独立置顶小窗。再次点击会唤回同一窗口。主窗与小窗同步本轮引用；在小窗点击字幕引用会回到主窗并定位对应记录和时间点。
- 小窗沿用中栏组件和 token，以 `body[data-window="mini"]` 呈现紧凑布局，并同步真实对话。

## 主要文件

- `src/tokens.css`：固定调色板、字体与尺寸 token。
- `src/components/ChamferCard.tsx`、`HudButton.tsx`、`StatusBadge.tsx`：原子组件。
- `src/components/HistoryPanel.tsx`：右栏列表、筛选、搜索和展开态。
- `src/components/Topbar.tsx`、`topbar.css`：顶栏命令区、拖动区域和原生窗口控制。
- `src/components/ChatPanel.tsx`、`chat.css`：上下文引用、真实对话、字幕定位和输入区。
- `src/components/AgentSetup.tsx`、`PersonaSetup.tsx`、`src/agent.ts`：模型配置、人格编辑与流式事件调用。
- `src/components/NotesPanel.tsx`、`src/notes.ts`：笔记草稿、追加、编辑及来源引用。
- `src/components/Sidebar.tsx`、`sidebar.css`：导航、快捷操作、禁用状态与窄窗口图标布局。
- `src/MiniApp.tsx`、`mini.css`：小窗标题栏、紧凑布局与跨窗口引用交互。
- `src/mini-window.ts`：WebviewWindow 创建、唤回及窗口事件类型。
- `src/chat-data.ts`：与真实记录 ID 和字幕时间对应的消息 fixture 类型及数据。
- `src/data.ts`：`KnowledgeRecord` 类型及 fixture。
- `src/records.ts`：从 Rust 本地资料库读取记录和扩展连接状态。
- `src/components/ExtensionSetup.tsx`：配对码和扩展安装说明。
- `extension/`：Chrome/Edge Manifest V3 扩展；点击工具栏图标捕获当前文章或视频字幕。
- `extension/video-extractor.js`：发现字幕轨道并解析 YouTube、Bilibili 与标准 WebVTT 字幕。
- `src-tauri/src/storage.rs`：文章、视频字幕与配对码的本地存储。
- `src-tauri/src/agent.rs`、`src-tauri/default-persona.md`：流式模型请求、人格文件、引用映射与对话存储。
- `src-tauri/src/context.rs`：组装模型文本上下文、控制长度并生成发送前预览；资料选择和历史截取在此实现。
- `src-tauri/src/notes.rs`、`src-tauri/src/workflow.rs`：笔记保存、Markdown 导出，以及笔记正文和工作状态的受控修改提案与操作记录。
- `src-tauri/src/bridge.rs`：只监听 `127.0.0.1:45147` 的本机扩展连接。
- `src-tauri/src/process_status.rs`：与 TypeScript 对应的 Rust 状态枚举。
- `src-tauri/capabilities/default.json`、`mini.json`：主窗与小窗各自的窗口权限。
- `VISUAL_GUIDE.md`：本阶段视觉规则与验收范围。
